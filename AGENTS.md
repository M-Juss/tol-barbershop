# Default Instructions

## Before making any changes

1. **Read first** — Always read the full file before editing it
2. **Follow conventions** — Check neighboring files for patterns (naming, typing, imports, component structure)
3. **No comments** — Never add comments to code unless explicitly asked
4. **Run checks** — After changes, run lint/typecheck or equivalent
5. **No commits** — Never commit unless explicitly asked
6. **No explanations** — Don't add code summary or explanation after edits unless asked
